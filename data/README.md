# Dataset Information – NorthStar Urban Mobility and Logistics

## Overview
This folder contains the datasets used for the NorthStar Urban Mobility and Logistics Databases and Analytics assignment. The datasets represent operational, customer service, delivery, fleet management, and application activity data used for SQL analysis, R analytics, Python data processing, and MongoDB implementation.

The datasets were analysed to identify operational inefficiencies affecting delivery performance, customer satisfaction, vehicle reliability, operational profitability, and application performance across the organisation.

---

## Dataset Files

### customers.csv
Contains customer information including:
- customer ID
- customer type
- loyalty score
- account status
- home operational zone

### orders.csv
Contains operational order information including:
- order ID
- service type
- order value
- pickup and dropoff zones
- priority levels

### complaints.csv
Contains customer complaint records including:
- complaint type
- severity level
- complaint status
- compensation amount
- resolution duration

### deliveries.csv
Contains delivery operation records including:
- delivery status
- dispatch timestamps
- route distances
- delivery completion information
- route override activity

### incidents.csv
Contains operational incident records including:
- incident type
- severity
- reported timestamps
- resolution status
- resolution duration

### drivers.csv
Contains driver operational information including:
- driver ratings
- employment type
- years of experience
- operational zones

### vehicles.csv
Contains fleet and vehicle monitoring data including:
- vehicle type
- maintenance status
- battery health
- odometer readings

### hubs.csv
Contains operational hub information including:
- hub identifiers
- operational zones
- hub types

### app_events.csv
Contains mobile application operational event data including:
- session IDs
- event types
- API latency
- device information
- success and failure activity

---

## Purpose of the Datasets
The datasets were used to:
- analyse delivery failures and delays
- investigate customer complaints
- evaluate operational efficiency
- monitor vehicle reliability
- identify customer satisfaction trends
- analyse application performance
- implement MongoDB document-oriented database structures
- perform query optimisation and aggregation analysis
