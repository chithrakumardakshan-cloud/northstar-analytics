# NorthStar Urban Mobility and Logistics Analytics

## Databases and Analytics Assignment – University of West London

### Overview
This repository contains the complete analytical implementation developed for the NorthStar Urban Mobility and Logistics case study. The project investigates operational inefficiencies affecting delivery performance, customer satisfaction, vehicle reliability, operational profitability, and application performance using SQL in R, R Analytics, Python Data Processing, and MongoDB technologies.

The implementation includes structured querying, statistical analysis, data visualisation, feature engineering, NoSQL document modelling, CRUD operations, aggregation pipelines, indexing strategies, explain plans, and query optimisation techniques.

---

## Repository Structure

### notebooks/01_sql_in_r.ipynb
This notebook contains:
- SQL queries executed within R using sqldf
- Filtering, grouping, joins, and aggregation
- Operational performance analysis
- Query optimisation analysis
- Business interpretations of SQL outputs

### notebooks/02_r_analytics.ipynb
This notebook contains:
- Data cleaning and preprocessing in R
- Summary statistics and correlation analysis
- ggplot2 visualisations and operational charts
- Delivery performance and customer analysis
- Statistical interpretation of operational trends

### notebooks/03_python_processing.ipynb
This notebook contains:
- Data preprocessing using pandas and NumPy
- Missing value analysis
- Feature engineering
- Grouped operational analysis
- Data visualisation using matplotlib and seaborn
- Operational performance investigation

### notebooks/04_mongodb_development.ipynb
This notebook contains:
- MongoDB Atlas database connection
- NoSQL document modelling
- CRUD operations
- Aggregation pipelines
- Index creation and optimisation
- Explain plan analysis
- Performance timing comparison
