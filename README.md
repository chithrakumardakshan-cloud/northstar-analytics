# NorthStar Urban Mobility and Logistics Analytics
## Databases and Analytics Assignment — University of West London

### Overview
This repository contains the complete analytical implementation developed for the NorthStar Urban Mobility and Logistics case study. The project focuses on analysing operational inefficiencies affecting delivery performance, customer satisfaction, vehicle reliability, operational profitability, and application performance using SQL in R, R Analytics, Python Data Processing, and MongoDB technologies.

The implementation includes structured querying, statistical analysis, data visualisation, feature engineering, NoSQL document modelling, CRUD operations, aggregation pipelines, and query optimisation techniques.

### Repository Structure
- notebooks/01_sql_in_r.ipynb  
  SQL querying, filtering, joins, aggregation, and optimisation analysis using R and sqldf.

- notebooks/02_r_analytics.ipynb  
  Statistical analysis, descriptive statistics, correlation analysis, and operational visualisations using R and ggplot2.

- notebooks/03_python_processing.ipynb  
  Data cleaning, preprocessing, feature engineering, missing value analysis, grouped operational analysis, and visualisation using Python.

- notebooks/04_mongodb_development.ipynb  
  MongoDB Atlas NoSQL implementation including document modelling, CRUD operations, aggregation pipelines, indexing, explain plans, and query optimisation.
